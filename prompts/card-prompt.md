# 暗記カード作成プロンプト

あなたには、学習アプリ「問題投稿」に読み込ませるための**暗記カードJSON**を作成してもらいます。
以下の仕様に厳密に従い、**JSONデータだけ**を出力してください（説明文・前置き・```jsonのようなコードブロック記号は一切不要です。そのままファイルとして保存するので、JSON以外の文字を含めないでください）。

## 全体のJSON形式

```
{
  "title": "暗記カードのタイトル",
  "description": "暗記カードの説明文",
  "subjectId": 0,
  "gradeId": 0,
  "allowFlip": false,
  "cards": [
    { "front": "表面の文字列", "back": "裏面の文字列" },
    { "front": "表面の文字列", "back": "裏面の文字列" }
  ]
}
```

### 各フィールドの説明

- `title`（文字列・必須）: 暗記カードのタイトル。60文字以内が目安。
- `description`（文字列・任意）: 暗記カードの説明文。200文字以内が目安。省略時は空文字列 `""` にしてください。
- `subjectId`（数値・必須）: 教科を表す番号。下記の表から選んでください。
- `gradeId`（数値・必須）: 学年を表す番号。下記の表から選んでください。
- `allowFlip`（真偽値・任意）: 表と裏を逆転して出題することを許可するかどうか。省略時は `false`。
- `cards`（配列・必須）: カードオブジェクトの配列。1枚以上必要です。

#### `subjectId` の対応表

| 値 | 教科 |
|---|---|
| 0 | 不明 |
| 1 | 国語 |
| 2 | 数学 |
| 3 | 理科 |
| 4 | 英語 |
| 5 | 社会(歴史) |
| 6 | 社会(地理) |
| 7 | 社会(公民) |
| 8 | 保健体育(保健) |
| 9 | 保健体育(実技) |

#### `gradeId` の対応表

| 値 | 学年 |
|---|---|
| 0 | 不明 |
| 1 | 1年 |
| 2 | 2年 |
| 3 | 3年 |
| 4 | 総合 |

## カードオブジェクトの形式

```json
{ "front": "apple", "back": "りんご" }
```

- `front`（文字列・必須）: カードの表面に表示する文字列（問い・単語など）。
- `back`（文字列・必須）: カードの裏面に表示する文字列（答え・意味など）。

## 作成時の注意点

- 1枚のカードには、表裏1組の情報だけを入れてください（表に複数の問いを詰め込まない）。
- 表面は短く簡潔に、裏面は表面に対応する答え・意味・説明を過不足なく書いてください。
- 用語の暗記カードの場合は「表=用語, 裏=意味」、単語帳の場合は「表=単語, 裏=訳語」のように、一貫した表裏の関係にしてください。
- 出力は上記の全体JSON形式1つだけとし、余計なテキストは含めないでください。
