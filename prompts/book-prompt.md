# 問題集作成プロンプト

あなたには、学習アプリ「問題投稿」に読み込ませるための**問題集JSON**を作成してもらいます。
以下の仕様に厳密に従い、**JSONデータだけ**を出力してください（説明文・前置き・```jsonのようなコードブロック記号は一切不要です。そのままファイルとして保存するので、JSON以外の文字を含めないでください）。

## 全体のJSON形式

```
{
  "title": "問題集のタイトル",
  "description": "問題集の説明文",
  "subjectId": 0,
  "gradeId": 0,
  "shuffleProblems": false,
  "problems": [
    { ... 問題オブジェクト ... },
    { ... 問題オブジェクト ... }
  ]
}
```

### 各フィールドの説明

- `title`（文字列・必須）: 問題集のタイトル。60文字以内が目安。
- `description`（文字列・任意）: 問題集の説明文。200文字以内が目安。省略時は空文字列 `""` にしてください。
- `subjectId`（数値・必須）: 教科を表す番号。下記の表から選んでください。
- `gradeId`（数値・必須）: 学年を表す番号。下記の表から選んでください。
- `shuffleProblems`（真偽値・任意）: 出題順のシャッフルを許可するかどうか。省略時は `false`。
- `problems`（配列・必須）: 問題オブジェクトの配列。1問以上必要です。

#### `subjectId` の対応表

| 値 | 教科 |
|---|---|
| 0 | 不明 |
| 1 | 国語 |
| 2 | 数学 |
| 3 | 理科 |
| 4 | 英語 |
| 5 | 社会(歴史) |
| 6 | 社会(地理) |
| 7 | 社会(公民) |
| 8 | 保健体育(保健) |
| 9 | 保健体育(実技) |

#### `gradeId` の対応表

| 値 | 学年 |
|---|---|
| 0 | 不明 |
| 1 | 1年 |
| 2 | 2年 |
| 3 | 3年 |
| 4 | 総合 |

## 問題オブジェクトの形式

`answerType` の値によって、必要なフィールドが変わります。**画像(`imageUrl`)には対応していません。画像が必要な問題は作成しないでください。**

共通フィールド:

- `problem`（文字列・必須）: 問題文。
- `answerType`（文字列・必須）: `"single"` / `"multiple"` / `"text"` / `"descriptive"` のいずれか。
- `explanation`（文字列・任意）: 解説。省略時は空文字列 `""`。

### 1. 単数選択（`answerType: "single"`）— 選択肢の中から正解を1つ選ぶ形式

```json
{
  "problem": "日本の首都はどこですか？",
  "answerType": "single",
  "choices": ["大阪", "東京", "京都", "名古屋"],
  "answer": [1],
  "shuffleChoices": true,
  "explanation": "日本の首都は東京です。"
}
```

- `choices`（文字列の配列・必須）: 選択肢一覧。2つ以上。
- `answer`（数値の配列・必須）: 正解の選択肢を `choices` 配列の**0始まりのインデックス**で指定。単数選択なので要素は1つだけ。
- `shuffleChoices`（真偽値・任意）: 選択肢の表示順シャッフルを許可するか。省略時は `false`。

### 2. 複数選択（`answerType: "multiple"`）— 選択肢の中から正解を複数選ぶ形式

```json
{
  "problem": "次のうち、素数をすべて選びなさい。",
  "answerType": "multiple",
  "choices": ["2", "4", "7", "9", "11"],
  "answer": [0, 2, 4],
  "shuffleChoices": true,
  "explanation": "2, 7, 11 が素数です。"
}
```

- `choices` / `answer` / `shuffleChoices` は単数選択と同じ形式ですが、`answer` に複数のインデックスを含められます（2つ以上）。

### 3. 単語記述（`answerType: "text"`）— 短い単語・語句を入力させる形式

```json
{
  "problem": "水の化学式を答えなさい。",
  "answerType": "text",
  "answer": ["H2O", "ｈ2ｏ"],
  "explanation": "水は水素原子2つと酸素原子1つからできています。"
}
```

- `answer`（文字列の配列・必須）: 正解として許容する文字列を**すべて**列挙してください。表記ゆれ（ひらがな/カタカナ、全角/半角、送り仮名の違いなど）が考えられる場合は、想定される表記をできるだけ多く含めてください。
- `choices` は使用しません（省略、または空配列 `[]` にしてください）。

### 4. 記述（`answerType: "descriptive"`）— AIが自動採点する自由記述形式

```json
{
  "problem": "光合成の仕組みについて説明しなさい。",
  "answerType": "descriptive",
  "modelAnswer": "植物が光のエネルギーを使って、二酸化炭素と水からデンプンなどの栄養分と酸素を作り出すはたらき。",
  "gradingCriteria": "「光エネルギーを利用すること」「二酸化炭素と水を材料とすること」「デンプン(栄養分)と酸素を作ること」の3点に触れていれば正解とする。",
  "explanation": "光合成は主に葉の葉緑体で行われます。"
}
```

- `modelAnswer`（文字列・必須）: 模範解答。
- `gradingCriteria`（文字列・任意）: AIが採点する際の基準。採点のポイントを箇条書き的に書くと精度が上がります。省略時は空文字列 `""`。
- `choices` / `answer` は使用しません。

## 作成時の注意点

- 問題文・選択肢・解説は、指定された学年・教科の学習者が理解できる言葉遣いにしてください。
- 1つの問題集の中で、複数の`answerType`を混在させて構いません。
- 正解が一意に決まるように問題文・選択肢を作成してください（曖昧な問題は避ける）。
- 出力は上記の全体JSON形式1つだけとし、余計なテキストは含めないでください。
